# 《一道》

一条如理作意的善心之道。

本库存放《一道》全部文章的原始文稿，共 183 篇，随网站同步更新。

## 缘起

本书缘起于 2023 年起作者在寺院所做的法工辅导：禅修者们在人际、做事、学修、禅修中遇到的真实困惑，与作者给出的回答。一问一答，整理成文，陆续连载，每五十篇结为一辑。

网站：<https://yidao.online>　·　微信公众号：一道ekapantha

## 怎么取用

点右上角绿色的 **Code** 按钮 → **Download ZIP**，可以一次拿走全部文章。也可以点进 `articles/` 只看其中某一篇。

每篇一个 Markdown 文件，文件名是「编号-标题」。每篇开头有一段结构化信息（编号、标题、所属辑、标签、一句话概括、日期），正文是「问：」与「答：」。
